How it works

Four simple steps. Nothing changes on your store until you say so.

1

Connect

Reads every product from your Shopify store through the Admin API.

2

Generate

Free AI writes descriptions, meta titles (≤ 60), meta descriptions (≤ 160) and image alt text.

3

Review

The guess checker flags anything not backed by facts. Edit, then approve.

4

Publish

Approved content is pushed back to Shopify. Try a dry run first.

Versions

All three versions are built and working.

Version 1

LIVE ✓

The core SEO workflow, from Shopify to AI and back.

  • Connects to Shopify (Dev Dashboard app, secure token)
  • Fetches all products automatically
  • AI-written SEO description, meta title and meta description
  • Results saved to a CSV you can open in Excel
  • Review dashboard: edit, preview and approve

Version 2

LIVE ✓

Smarter checks and more SEO coverage, all inside the same chatbot.

  • Guess checker: flags sentences not backed by real product facts
  • One click to remove flagged guesses
  • Image alt text: the AI looks at each product photo and describes it
  • Collection pages: SEO description, meta title and meta description
  • Review page with tabs: Products, Collections, Image alt text
  • Chatbot handles all of it: "write alt text for my images", "check for guesses"…
  • Edited after publishing? It asks you to approve and publish again

Version 3

LIVE ✓

Safer for real stores, and ready for clients.

  • Each store keeps its own data; the demo never shows client data
