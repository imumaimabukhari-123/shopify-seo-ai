User Guide

Everything you need to use the Shopify AI SEO Generator, explained simply. You don't need to know anything about Shopify or SEO to follow this.

What this tool does

When people search on Google, it decides which shops to show using the text on each page. Good text = more visitors. Writing it by hand for hundreds of products takes days.

This tool connects to a Shopify store and uses AI to write that text for you:

  • Product descriptions: the text shoppers read on a product page.
  • Meta titles & meta descriptions: the blue headline and the short grey text Google shows in its results.
  • Image alt text: a short description of each product photo, for Google Images and for blind shoppers.
  • Collection pages: text for category pages like "Snowboards".

It can also score a store's SEO out of 100, undo anything it published, and work on several client stores (Version 3).

The key idea: the AI writes, you decide. Nothing changes in the store until you approve it and press Publish.

Demo vs owner

This website can be used in two ways:

👀 Visitor (no login needed)

  • Look around every page and read all the AI results on the Review page.
  • Ask the Chat questions, e.g. "What does the guess checker do?" (limited to 10 messages per hour).
  • Buttons that change things are hidden. The demo is read-only, so nobody can change the store.

  • Click Owner login in the top bar and enter the password.

Running the tool on your own computer? Then there's no login at all. Only you can reach it.

Product SEO (Version 1)

Write new descriptions, meta titles and meta descriptions for your products.

  1. Open Review → Products tab.
  2. For a first try, type 3 in Limit, then click 1. Generate. A black box shows progress. Each product takes about 10–20 seconds.
  3. Read each product card. The left side is what's in the store now; the right side is the AI's version.
  4. Change anything you like by typing in the boxes. It saves when you click outside the box. The counters (e.g. 43/60) turn red if text is too long. Click Show preview to see the description as shoppers will.
  5. Tick Approve on the ones you're happy with.
  6. Tick Dry run and click 2. Push approved to Shopify. The black box lists what would change. Nothing is changed yet.
  7. Untick Dry run, click 2. Push approved to Shopify again and confirm. The badge turns green: published.
Use the filter buttons (Needs review, Approved, not pushed, Published, Errors) to find things quickly. Leave Limit empty to do all products. Ones that are already done are skipped automatically.

Guess checker (Version 2)

AI sometimes "fills in the gaps" and invents details. Example: it called a snowboard "perfect for the terrain park" when the product information never said that. The guess checker is a second AI that compares the text with the real product facts (name, brand, type, tags, original description) and flags anything that isn't backed up.

  1. It runs automatically after each Generate. For older text, click Check for guesses at the top of the Review page.
  2. Click the Has guesses filter. Each flagged card shows a yellow box listing the guesses and why each one was flagged.
  3. Click Remove guesses from description to delete them in one go (the whole bullet point or sentence is removed). Or edit the text yourself.
  4. Guesses inside the meta title or meta description aren't removed automatically. Edit those boxes by hand.
Few facts = many guesses. If a product has no description at all, almost every specific claim is a guess. The fix is to give the AI more facts: add a short real description (material, size, who it's for) in Shopify, then generate again.

A green box (✓ everything is backed by your product info) means nothing was flagged.

Image alt text (Version 2)

The AI looks at each product photo and writes a short, accurate description, e.g. "The Complete Snowboard showing the teal and purple abstract geometric base and top design."

  1. Open Review → Image alt text tab.
  2. Click 1. Generate. Each photo appears with its old and new alt text.
  3. Edit if needed (max 125 characters), tick Approve, then Dry run → Push as above.

Collections (Version 2)

Collections are category pages. The AI writes their description, meta title and meta description using the collection's name and the products inside it.

  1. Open Review → Collections tab.
  2. Click 1. Generate, check the guesses, edit, approve, then Dry run → Push.

Backup & undo (Version 3)

Changed your mind after publishing? Undo puts the old text back on the store.

  1. Every time you publish, the tool first saves a backup: an exact copy of what the store had.
  2. On the Review page, published cards have an ↶ Undo button. Click it and confirm.
  3. The old text is back on Shopify, and the card shows undone. The AI's text is still there, so you can approve and publish it again any time.
  4. Clicking Undo one more step goes back one more publish, if there was one.
Things published before Version 3 have no exact backup. For those, Undo uses the original text saved in the CSV. It's the same words, but any bold text or bullet lists in the old description are lost.

Owners can download every backup as a spreadsheet at /download/backups.

SEO audit & score (Version 3)

The Audit page checks every product and collection against simple SEO rules and gives each a score out of 100. The store score is the average. It uses no AI, so it's free and takes seconds.

  • Meta titles: missing, longer than 60 characters, very short, or the same on two pages.
  • Meta descriptions: missing, longer than 160 characters, or very short.
  • Descriptions: missing, or under 50 words (30 for collections).
  • Image alt text: photos without alt text, or alt text over 125 characters.

Two kinds of audit

Free audit of any Shopify store: type a store's address. It only reads the store's public pages, so anyone can use it, with no login or access needed. It's a great way to show a possible client what's wrong with their store.

Full audit: the owner clicks Run full audit (or tells the chat "audit my store"). It uses the Shopify connection, so it also sees the hidden meta tags and checks collections.

Problems marked Fix with AI → can be fixed on the Review page: Generate, check, approve, publish. Then run the audit again and watch the score go up.

Client stores (Version 3)

Work on a client's store with their permission. Each store keeps its own CSVs, backups and audit, so stores never mix.

  1. Open Stores (owner only). It lists the exact steps, with copy buttons.
  2. Make one small app for the client in the Shopify Dev Dashboard, and choose Custom distribution for their store.
  3. Paste that app's Client ID and Client secret into Add store, then click Connect and approve on Shopify's page.
  4. Click Work on this store. A yellow label in the top bar shows which client store you're on. Review, Audit and Chat now use that store.
  5. To go back to the demo store, open Stores and click Work on this store on the main store.
Visitors of the public demo always see the main (demo) store, never a client's data. Client app keys and tokens are saved in stores.json on your computer. That file is never uploaded to GitHub.

Excel / CSV (optional)

Prefer spreadsheets? Click Download CSV on the Review page (one file per tab) and open it in Excel or Google Sheets. The new_… columns are the AI's text, and current_… is what's in the store now. On your own computer you can edit the file, type yes in the approved column, save it, close Excel, and then publish.

Safety: nothing changes without you

  • Generating only saves suggestions. The store is untouched until you push.
  • Only approved items are published, and each one only once.
  • Dry run lets you preview every publish.
  • If you edit text after publishing, it's marked edited and needs approving again.
  • Every publish saves a backup first, and Undo puts the old text back.
  • Empty fields are never sent, so existing text can't be wiped by accident.
  • Online, visitors are read-only and the owner needs a password.

Set it up for your own store

About 20 minutes, completely free. Click each step to open it.

1. Create a free Shopify Partner account
  1. Go to shopify.com/partners and click Join now.
  2. Sign up (e.g. with Google). Choose Create a new partner organization, focus Build apps, and fill in your details.
If you see "Start your free trial… $1/month", you're on the paid store sign-up. Go back and use the Partners page instead.
2. Create a free development store
  1. From the Partners page, click Dev dashboard (bottom-left).
  2. Click + Create a store → choose Dev.
  3. Give it a name, pick any plan (it's free on dev stores), and tick Generate test data to get sample products.
Create the store from the Dev Dashboard, not with "Create new store" elsewhere. Otherwise the app can't connect.
3. Create the app and give it permissions
  1. In the Dev Dashboard go to Apps and click Create app in the "Get API credentials" bar at the bottom.
  2. App name: SEO Generator. Leave App URL as it is and untick "Embed app in Shopify admin".
  3. In Scopes, type: read_products,write_products,read_files,write_files
  4. Click Release, then Install app and choose your store. (Landing on an "example.com" page afterwards is normal.)
  5. Open App settings and copy the Client ID and Secret.
4. Get a free AI key (Google Gemini)
  1. Go to aistudio.google.com/apikey and sign in with Google.
  2. Click Create API key and copy it. No credit card needed.
5. Put the keys in the settings file and start

Copy .env.example to .env and fill in:

SHOPIFY_STORE_DOMAIN=your-store.myshopify.com
SHOPIFY_CLIENT_ID=your-client-id
SHOPIFY_CLIENT_SECRET=your-secret
GEMINI_API_KEY=your-gemini-key

Then, in a terminal in the project folder:

venv\Scripts\activate
python cli.py check      # tests the Shopify + AI connection
python app.py            # starts the website

Open http://127.0.0.1:8001. Keep keys only in .env. Never share that file.

FAQ

Is it really free?

Yes. Shopify dev stores, the Partner account and the Gemini API free tier cost nothing. The free AI has speed limits, so the tool waits a few seconds between products.

Can it break my store?

No. It only changes descriptions, meta titles/descriptions and image alt text, and only for items you approve. Prices, stock, orders and design are never touched.

What if the AI writes something wrong?

That's why everything goes through review. The guess checker flags invented details, and you can edit or remove anything before publishing.

How long does it take?

About 10–20 seconds per product on the free AI plan (it writes the text, then double-checks it). 100 products ≈ 30 minutes, running by itself.

It says "rate limit" or "429"

The free AI allowance is used up for the moment. Wait a few minutes and click Generate again. It continues where it stopped.

Does it work on a real (paid) store?

Yes. The same steps work. Try it on a dev store first, and always use Dry run before publishing.
